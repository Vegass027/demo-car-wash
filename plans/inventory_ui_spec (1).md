## 3. Элементы интерфейса

### 3.1 Шапка карточки
- **Название товара** (крупный шрифт): "Шампунь Koch"

### 3.2 Прогресс-бар
- **Визуальная полоска** показывает остаток в процентах
- **Процент** отображается справа от полоски: "80%"
- **Текстовая информация** под полоской: "Сейчас на складе: 16 канистр"

### 3.3 Блок управления

#### Радиокнопки (переключатель действия)
- **Тип:** Radio buttons (только один может быть выбран)
- **Две опции:**
  - ○ Привезли товар
  - ○ Пересчитали остатки

#### Поле ввода количества
- **Одно универсальное поле** для обоих действий
- **Единица измерения** справа: "канистр" (или литр, упаковка и т.д.)
- **Всегда видимое** независимо от выбранной радиокнопки

#### Кнопка сохранения
- **Текст:** "СОХРАНИТЬ"
- **Расположение:** по центру, под всеми полями

## 5. Логика переключения полей

### Когда админ выбирает "Привезли товар":
1. Появляется поле "Сумма по накладной"
2. Появляется кнопка "Сфотографировать"
3. Оба поля (Количество и Сумма) становятся обязательными
4. Под полем "Сумма" автоматически показывается цена за единицу

### Когда админ выбирает "Пересчитали остатки":
1. Поле "Сумма" исчезает
2. Кнопка "Сфотографировать" исчезает
3. Обязательное только поле "Количество"

## 6. Работа кнопки "Сфотографировать"

### Что происходит при клике:

**На мобильном телефоне:**
- Открывается камера
- Админ фоткает накладную
- Фото сразу загружается

**На компьютере:**
- Открывается выбор файла
- Админ выбирает файл с компьютера
- Файл загружается

### Форматы файлов:
- ✅ JPG / JPEG
- ✅ PNG
- ❌ PDF — НЕ принимать
- ❌ DOC, XLS и другие — НЕ принимать

### После загрузки файла:

```
Фото накладной:
[📷 Сфотографировать]

📷 накладная_стр1.jpg    [×]
📷 накладная_стр2.jpg    [×]
```

- Каждый файл показывается отдельной строкой
- Справа от каждого файла — крестик [×]
- Можно загрузить несколько файлов (если накладная на нескольких листах)

### Кнопка [×] (удалить фото):

**Что происходит:**
- Файл удаляется из списка
- Админ может сфотать заново
- Можно удалить любой файл из списка

## 7. Автоматический расчёт цены за единицу

### Когда показывается:
- Только в режиме "Привезли товар"
- Появляется под полем "Сумма по накладной"

### Как считается:
```
Админ ввёл:
- Количество: 30
- Сумма: 75000

Система автоматически считает:
75000 ÷ 30 = 2500 ₽ за канистру

И показывает:
💡 2500 ₽ за канистру
```

### Зачем это нужно:
- Админ сразу видит цену за единицу
- Может заметить если ошибся в вводе
- Может заметить если поставщик наебал с ценой

## 8. Валидация (когда кнопка "Сохранить" активна)

### Режим "Привезли товар":

**Кнопка АКТИВНА когда:**
- ✅ Поле "Количество" заполнено (число больше 0)
- ✅ Поле "Сумма" заполнено (число больше 0)
- ⚠️ Фото необязательно (можно сохранить без фото)

**Кнопка НЕАКТИВНА (серая) когда:**
- ❌ Поле "Количество" пустое
- ❌ Поле "Сумма" пустое
- ❌ В полях введён ноль или отрицательное число

### Режим "Пересчитали остатки":

**Кнопка АКТИВНА когда:**
- ✅ Поле "Количество" заполнено (число >= 0)

**Кнопка НЕАКТИВНА когда:**
- ❌ Поле "Количество" пустое
- ❌ В поле введено отрицательное число

## 9. Цветовая схема прогресс-бара

### Логика окраски:

- **≥ 70%** → **Зелёный** (всё хорошо)
- **40-69%** → **Жёлтый** (рабочий режим)
- **15-39%** → **Оранжевый** (пора заказывать)
- **< 15%** → **Красный** (критично, срочно звонить поставщику)

### Примеры:
```
80% → ████████████████░░░░░ (зелёный)
50% → ██████████░░░░░░░░░░ (жёлтый)
30% → ██████░░░░░░░░░░░░░░ (оранжевый)
10% → ██░░░░░░░░░░░░░░░░░░ (красный)
```

## 11. Главный экран склада (АККОРДЕОН)

### ВАЖНО: Используется механика АККОРДЕОН (accordion)

**Что это значит:**
- Все товары видны сразу в свёрнутом виде
- Клик на товар → раскрывается форма управления (ПУМС вниз)
- Клик повторно → форма закрывается (ПУМС обратно вверх)
- Открыта может быть только ОДНА карточка (другие автоматически закрываются)
