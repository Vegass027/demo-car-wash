### Вариант 1: Сначала чек, потом сумма

**Шаг 1:** Нажимаешь `[📎 Чек]`
```
☕ Чай/Кофе   [      ]₽  [📎 Чек]  [💾 Сохранить]
                          ↑ открывается выбор файла
```

**Шаг 2:** Выбираешь фото/PDF чека → загружается
```
☕ Чай/Кофе   [      ]₽  [📎✓]  [💾 Сохранить]
                          ↑ галочка = чек загружен
```

**Шаг 3:** Вбиваешь сумму
```
☕ Чай/Кофе   [ 500  ]₽  [📎✓]  [💾 Сохранить]
```

**Шаг 4:** Нажимаешь `[💾 Сохранить]` — ВСЁ!
