# План реализации: "Кто работает сегодня"

## Задача

Добавить возможность отмечать, какие мойщики работают сегодня. Только тем мойщикам, кто отмечен как "работает сегодня", будет начисляться базовая ставка 500₽.

## Что нужно сделать

### 1. Обновить тип Worker
Добавить поле `isWorkingToday: boolean` в интерфейс Worker в файле types.ts

### 2. Обновить логику инициализации дня
В функции `initializeWorkersDay()` в файле features/workers/calculateEarnings.ts:
- Установить `isWorkingToday = false` для всех мойщиков
- Установить `earnedToday = 0` (без базовой ставки)

### 3. Добавить функцию переключения
В файле features/workers/calculateEarnings.ts создать функцию `toggleWorkerWorkingToday()`:
- Принимает массив workers, workerId и флаг isWorking
- Переключает `isWorkingToday` для указанного мойщика
- Если `isWorking = true` → устанавливает `earnedToday = 500`
- Если `isWorking = false` → устанавливает `earnedToday = 0`

### 4. Обновить AssignWorkerModal
В файле components/admin/AssignWorkerModal.tsx:
- Фильтровать список мойщиков: показывать только тех, у кого `isWorkingToday = true`
- Если мойщик НЕ работает сегодня, он НЕ отображается в списке для назначения

### 5. Обновить App.tsx
- Добавить обработчик `handleToggleWorkerWorking(workerId: string, isWorking: boolean)`
- Передать этот обработчик в Workers компонент как проп `onToggleWorkerWorking`
- Обновить mock данные: добавить `isWorkingToday: false` для всех мойщиков

### 6. Обновить Workers.tsx
- Добавить Toggle Switch рядом с кнопкой "Заказы за сегодня"
- Toggle должен быть в стиле iOS (слайдер)
- При клике вызывать `onToggleWorkerWorking(worker.id, !worker.isWorkingToday)`
- Показывать зеленый цвет когда включен, серый когда выключен

### 7. Обновить WorkerBookingsList.tsx
- Добавить проп `worker.isWorkingToday`
- В карточке "Итого за день" показывать базовую ставку 500₽ ТОЛЬКО если `worker.isWorkingToday = true`
- Если мойщик не работает сегодня и нет заказов - показывать сообщение "Мойщик не работает сегодня"

## Логика работы

### Если мойщик работает сегодня (isWorkingToday = true):
- Базовая ставка: 500₽
- Проценты от заказов: начисляются
- Итого: 500₽ + проценты
- Мойщик отображается в списке для назначения на заказы

### Если мойщик НЕ работает сегодня (isWorkingToday = false):
- Базовая ставка: 0₽
- Проценты от заказов: НЕ начисляются
- Итого: только проценты
- Мойщик НЕ отображается в списке для назначения на заказы

## Пример

**Сценарий: Вася работает сегодня**
1. Админ отмечает "Работает сегодня" → isWorkingToday = true, earnedToday = 500₽
2. Заказ 1 (1800₽) выполнен → earnedToday = 500 + 720 = 1220₽
3. Заказ 2 (3500₽) выполнен → earnedToday = 1220 + 1400 = 2620₽
4. Итого за день: 500 + 720 + 1400 = 2620₽

**Сценарий: Петя НЕ работает сегодня**
1. Админ НЕ отмечает "Работает сегодня" → isWorkingToday = false, earnedToday = 0₽
2. При открытии AssignWorkerModal - Петя НЕ отображается в списке
3. При открытии "Заказы за сегодня" → показывается "Мойщик не работает сегодня"
4. Заказы НЕ могут быть назначены на Петю (пока не работает)
5. Если Петя начнет работать → isWorkingToday = true, earnedToday = 500₽, появляется в списке назначения
